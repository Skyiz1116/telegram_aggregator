# Сборщик корпоративных переписок в Telegram

Модульная система для автоматического сбора сообщений (текст, документы, изображения, реакции) из корпоративных чатов Telegram и их выгрузки администраторам за определённый период.

## Технологический стек
- Python 3.8+
- PostgreSQL (база данных)
- SQLAlchemy (ORM для работы с БД)
- python-telegram-bot (интеграция с Telegram API)
- python-dotenv (управление переменными окружения)

## Инструкция по запуску

### 1. Клонируйте репозиторий и перейдите в папку проекта:
git clone https://github.com/Skyiz1116/telegram_aggregator.git
cd telegram_aggregator

### 2. Создайте и активируйте виртуальное окружение:
python -m venv venv
venv\Scripts\activate  (для Windows)
# или source venv/bin/activate (для macOS/Linux)

### 3. Установите зависимости:
pip install -r requirements.txt

### 4. Настройте файл .env
Создайте в корне проекта файл с именем `.env` (точка в начале обязательна) и заполните его следующими переменными:

| Переменная | Описание | Пример заполнения |
|------------|----------|-------------------|
| `BOT_TOKEN` | Токен вашего Telegram-бота, полученный от @BotFather. Нужен для авторизации бота в Telegram API. | `123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxx` |
| `DATABASE_URL` | Строка подключения к базе данных PostgreSQL. Без неё приложение не сможет сохранить или прочитать данные. | `postgresql://postgres:12345@localhost/telegram_db` |
| `ADMIN_ID` | Числовой ID вашего Telegram-аккаунта. Нужен для того, чтобы только вы (администратор) могли использовать команды выгрузки данных. Получить ID можно у бота @userinfobot. | `987654321` |

⚠️ **Важно:** Файл `.env` содержит секретные данные (токен и пароль от БД). Он добавлен в `.gitignore` и **НЕ должен** загружаться на GitHub. Каждый, кто клонирует проект, создаёт свой `.env` со своими данными.

### 5. Инициализируйте базу данных:
Убедитесь, что PostgreSQL запущен и база данных `telegram_db` создана. Затем выполните:
python -c "from database import create_tables; create_tables()"

### 6. Запустите приложение:
python main.py

## Структура проекта (Модульная архитектура)
telegram_aggregator/
├── database.py          # Модуль интеграции с БД (SQLAlchemy, модели)
├── bot_collector.py     # Модуль сбора данных из Telegram (сохранение в БД)
├── bot_admin.py         # Модуль интерфейса администратора (команды выгрузки)
├── main.py              # Общий модуль (точка входа, соединение всех модулей)
├── .env                 # Секретные переменные (не загружается на GitHub)
├── .gitignore           # Настройки игнорирования файлов
├── requirements.txt     # Список зависимостей
└── README.md            # Документация проекта

## Команды администратора
- `/start` — проверка связи с ботом
- `/export <дата_начала> <дата_конца>` — выгрузка истории переписки за указанный период (например: `/export 2024-01-01 2024-01-31`)
